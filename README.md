## Sandbox topology

This sandbox consists of two networked hosts in a LAN:

* attacker - Kali Linux 2020 with GUI at IP `10.10.10.10`,
* server - headless Ubuntu 18.04 Server running Telnet at IP `10.10.10.20`.

## Usage

1. Clone this repository locally.
2. Run `vagrant up` in the directory with this repository to instantiate the sandbox.
3. Access Kali via VirtualBox console. Log in as `kali` with `kali` as password.
4. Enjoy.
